# CS2 Match Analyzer — Agent context

Hệ thống cá nhân / SaaS nhỏ: lấy lịch sử trận CS2 từ Steam/Valve, tải demo, parse event & stats, phân tích điểm mạnh/yếu, xem lại qua **video + timeline marker** (không phải replay 2D/minimap).

## Product direction (bắt buộc)

- **Không** làm minimap / replay 2D trong MVP.
- UX replay = video bình thường + marker trên thanh thời gian; click marker → `seek` đúng `time_seconds`.
- Icon marker: kill → crosshair; death → skull; assist; bomb plant; defuse; clutch → star; multi-kill nổi bật hơn.
- Không đưa raw demo / raw event dài cho AI; pipeline: events → stats → patterns → rule-based analysis → (optional) LLM summary.

## MVP scope

**Trong MVP:** Steam connect; match token + auth code; fetch match; download demo; parse; DB; match history; stats/trận; rule-based analysis; timeline markers; video viewer + markers.

**Sau MVP:** server render video HQ; auto clip highlight; AI coach phức tạp; so sánh cộng đồng; ranking skill; mobile app; anti-cheat.

Chi tiết: `docs/agents/cs2-product.md`.

## Pipeline chính

```text
User → Web App → Backend API → Match Fetcher → Demo Downloader → Demo Parser → DB → Dashboard
```

Chi tiết workers & module: `docs/agents/cs2-architecture.md`.

## Triển khai: mock trước, tích hợp thật sau

1. Mock: match, rounds, events, markers, analysis report → đóng UI/UX + data model.
2. Sau: Steam fetcher, demo downloader, parser, analysis generator, video pipeline.

Không implement Steam API / demo parser thật cho đến khi UI + schema ổn — dùng interface + mock adapter.

## Acceptance criteria (MVP)

1. Connect Steam account.
2. Nhập match token / auth code.
3. Lấy ≥1 match mới.
4. Tải được demo.
5. Parse kill/death/round/basic stats.
6. Match detail: map, score, player stats, rounds, events.
7. Analysis: strengths, weaknesses, recommendations.
8. Timeline: kill, death, bomb, highlight markers.
9. Click marker → seek video đúng thời điểm.
10. Queue: retry + status rõ (`pending` → `parsed` / `failed`).

Khi implement feature, đọc tài liệu liên quan **trước** khi viết code.
